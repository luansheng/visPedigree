# Internal layout engine for pedigree visualization

Internal layout engine for pedigree visualization

## Usage

``` r
prepare_ped_graph(
  ped,
  compact = FALSE,
  outline = FALSE,
  cex = NULL,
  highlight = NULL,
  trace = FALSE,
  showf = FALSE,
  labelvar = NULL,
  shapeby = "sex",
  pagewidth = 200,
  symbolsize = 1,
  maxiter = 1000,
  ...
)
```
