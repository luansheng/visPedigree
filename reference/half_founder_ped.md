# A pedigree with half founders

A dataset from ENDOG containing individuals with a single missing parent
(half founders). Useful for testing genetic algorithms correctly
conserving probability mass for missing lineages.

## Usage

``` r
half_founder_ped
```

## Format

A data.frame with 4 columns:

- Ind:

  Individual ID

- Sire:

  Sire ID

- Dam:

  Dam ID

- Sex:

  Sex of the individual
