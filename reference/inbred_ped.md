# A highly inbred pedigree

A simulated pedigree designed to demonstrate high levels of inbreeding
and partial inbreeding decomposition. Contains full-sib mating and
backcrossing.

## Usage

``` r
inbred_ped
```

## Format

A data.table with 5 columns:

- Ind:

  Individual ID

- Sire:

  Sire ID

- Dam:

  Dam ID

- Sex:

  Sex of the individual

- Gen:

  Generation number
