# Compact pedigree by merging full siblings

Compact pedigree by merging full siblings

## Usage

``` r
compact_pedigree(ped_node, compact, h_ids)
```

## Arguments

- ped_node:

  A data.table of nodes.

- compact:

  Logical, whether to compact.

- h_ids:

  Highlighted IDs to exempt from compaction.
