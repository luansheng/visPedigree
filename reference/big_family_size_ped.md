# A large pedigree with big family sizes

A dataset containing a pedigree with many full-sib individuals per
family.

## Usage

``` r
big_family_size_ped
```

## Format

A data.table with 7 columns:

- Ind:

  Individual ID

- Sire:

  Sire ID

- Dam:

  Dam ID

- Sex:

  Sex of the individual

- Year:

  Year of birth

- IndNum:

  Numeric ID for individual

- SireNum:

  Numeric ID for sire

- DamNum:

  Numeric ID for dam
